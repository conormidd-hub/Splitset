## How to read the tables

| Column | Meaning |
|---|---|
| Primary · 1.0 | The muscle the exercise is for. It limits the set. Gets the full exercise load. |
| Secondary · 0.4 | Does real work but does not limit the set. Gets 40% of the exercise load. |
| Tertiary · 0.2 | Stabilises or assists. Fatigues, is not trained. Gets 20%. |
| Load split | Where one set's load lands on the body, as % of the total the exercise hands out. Show this in the exercise picker. |
| Fatigue | `high` × 1.2, `standard` × 1.0, `low` × 0.8 on the exercise load. High = heavy free-weight compounds and big-stretch eccentrics; low = machines, cables, bands, calf raises, light core. |
| Mode | `weight`: logged weight × reps. `BW × f`: effective weight = bodyweight × f + added load. `− assist`: minus the machine's assistance. `fixed`: no usable weight; each working set costs a fixed amount (spec §4.3). `uni`: unilateral, one logged set covers both sides. |
| PB estimate | Where the starting PB comes from before this exercise has any history (spec §3.4): a related lift × ratio, `first session` (calibrated from the first workout), or `anchor` (a root lift others estimate from). |
